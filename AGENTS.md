# Search Middleware

MySQL ↔ ZincSearch 双向索引同步中间件：SQL 配置驱动文档组装、零停机全量重建、增量游标同步、搜索 API、JWT 鉴权、定时调度。Go 单二进制。

详见 `README.md`（快速开始/目录结构/API 摘要/测试）。
