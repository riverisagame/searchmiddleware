# Web GUI 设计（Vue3 + Element Plus）

> 日期：2026-08-05 | 独立前端 web-ui/（Vite + Vue3 + Element Plus + Pinia + 路由），构建产物 Go embed 进单二进制

## 技术形态

- 开发：`npm run dev`（vite，proxy `/api` → Go 服务 :8090）
- 生产：`npm run build` → dist → **Go embed**（`//go:embed web-ui/dist`）→ 单二进制含 GUI
- 布局：Element Plus 经典 admin 布局（左侧菜单 + 顶栏：当前用户/退出）
- 登录页（JWT）→ 角色 admin/viewer（viewer 隐藏管理操作按钮）

## 页面清单

### 1. 仪表盘（索引概览）
- 索引卡片：文档数 / 上次同步时间 / 落后秒数 / 增量游标 / **健康度三色**（🟢🟡🔴）
- 趋势：最近 24h 搜索量 / 同步任务成功失败分布（ECharts 或轻量图表）
- 告警条：sync_alerts 未读列表

### 2. 同步中心
- 手动触发：全量重建（走零停机 alias）/ 增量 / 指定 id 重建
- 运行历史表格：索引/类型/触发方式/行数/耗时/吞吐/状态（success/failed/skipped/interrupted）
- 失败任务：查看 failed_ids → **一键重试失败批**
- 并行状态：running/queued/skipped

### 3. 定时任务（调度管理）
- 任务列表：索引/类型（full/incremental）/cron 表达式/启停开关/上次执行/下次执行
- 新建/编辑：选择索引 → 类型 → 周期（预设：每天/每小时/每 5 分钟/自定义 cron）→ 执行时间（每天时选几点）→ 保存
- 手动"立即执行"按钮
- 默认任务（首次启动生成）：增量 5 分钟 + 每日全量 02:00

### 4. 日志中心
- 筛选：索引/级别/类型/时间范围；分页
- 慢查询标色（>1s 黄 / >10s 红）；错误详情抽屉（含 SQL 摘要）

### 5. 对账中心
- 两级结果展示：COUNT 对比（总览表）+ id 级差异清单（缺同步/脏文档）
- 差异行操作：单条补同步 / 一键全部补同步（重建缺的、删除多的）

### 6. 索引配置编辑器（核心）
- 索引列表：新建/编辑/删除/复制（从模板 `_example.yaml`）
- 编辑页 Tab：
  - **基本信息**：名称/数据源/别名/分析器（下拉：jieba 模式/gse）
  - **主 SQL**：代码编辑器（高亮）+ 【试跑】按钮 → 预览前 20 行（列名+样例行）
  - **属性 SQL**：多个（sql_joined_field）逐个试跑验证
  - **字段映射**：保存时自动探测列名 → 表格（字段/类型下拉/权重/可过滤/可排序/可聚合开关）
  - **权重 boost**：表格（字段 × 权重）
  - **高级**：mapping_options / 词典路径 / 增量字段 / min_word_len
- 保存：校验（yaml 解析 → 类型合法 → SQL 试跑）→ 写 DB + 原子写文件 → 提示"配置已变更，索引需重建"（一键重建按钮）
- 配置变更检测：mapping 变化 → 需重建；仅权重 → 热加载生效

### 7. 同义词管理
- 表格：word / synonyms 列表 / 作用索引；增删改查
- 说明：查询期扩展（QueryBuilder），保存即生效（无需重建）

### 8. 告警中心
- sync_alerts 列表（时间/索引/级别/消息/已读状态）
- webhook 通知配置（预留，实现后置）

### 9. 用户管理（admin）
- 用户列表：用户名/角色/创建时间；创建/重置密码/禁用
- 首次启动：CLI `searchmiddleware user:create admin` 或 GUI 初始化页引导

## 主题与体验

- Element Plus 亮/暗主题切换
- 配置编辑即所见（试跑验证）、错误内联提示（文件:行号）
- 全部操作有操作确认（重建/删除/回退二次确认）
